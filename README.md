### Hi, I'm Matheswaran

I build tools for Salesforce Marketing Cloud, Data Cloud and Personalization. Lately that means MCP servers that give AI assistants direct access to those platforms, plus developer utilities for the things the UIs don't do.

**MCP servers**

- [mcp-sfmc](https://github.com/matheswarwan/mcp-sfmc): 128 tools covering the SFMC REST and SOAP APIs. On npm as [`mcp-sfmc`](https://www.npmjs.com/package/mcp-sfmc).
- [datacloud-mcp](https://github.com/matheswarwan/datacloud-mcp): Data Cloud (Data 360) streams, DMOs, segments, calculated insights, identity resolution and data graphs.
- [mcp-interaction-studio](https://github.com/matheswarwan/mcp-interaction-studio): Interaction Studio / Marketing Cloud Personalization admin APIs.

**Data Cloud and Personalization**

- [unified-profile-explorer](https://github.com/matheswarwan/unified-profile-explorer): look up an individual across Data Cloud orgs and render the full profile from every linked DMO.
- [personalization-point-simulator-lwc](https://github.com/matheswarwan/personalization-point-simulator-lwc): fire the Personalization Decisioning API from a Personalization Point record page.
- [sfmc-migration-tool](https://github.com/matheswarwan/sfmc-migration-tool): inventory an SFMC org and score how hard a move to Marketing Cloud Next will be.

**Marketing Cloud developer tools**

- [sfmc-chrome-addon-2023](https://github.com/matheswarwan/sfmc-chrome-addon-2023): a Chrome extension that keeps a version history of Content Builder saves.
- [MjmlRender](https://github.com/matheswarwan/MjmlRender): write MJML in a Content Builder block and get email-safe HTML as you type.
- [sfmc-two-way-mobile-chat](https://github.com/matheswarwan/sfmc-two-way-mobile-chat): a two-way SMS conversation console for Marketing Cloud messaging.
- [Renderly](https://github.com/matheswarwan/Renderly): email rendering previews in real clients, without a Litmus subscription.
